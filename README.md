# 招新报名数据清洗与统计

协会每年招新都会收到几百份报名表（从问卷导出的 CSV）。

此工具可以完成下列需求：  
**【需求 1】读入与概览**  
· 读入 CSV（字段：姓名、学号、邮箱、志愿1、志愿2、推荐人）  
· 打印概览：一共多少行、每列有多少个空值、有没有完全重复的行  
**【需求 2】校验与清洗**  
· 学号必须是纯数字；邮箱必须是 学号@smbu.edu.cn（对不上就是填错了）  
· 找出重复报名（同一学号出现两次）  
· 不要直接改原文件：把有问题的行单独导出一份「问题清单」，并写明每行为什么被判为有问题  
**【需求 3】统计与导出**  
· 按第一志愿分组统计人数，输出一张汇总表  
· 统计两个志愿都填了的人有多少、只填一个的有多少  
· 把清洗后的干净数据导出成新 CSV  

只用了 Python 自带的标准库，不需要 pip 装任何东西。  

## 目录

```
.
├── main.py                 主程序，三个子命令
├── make_sample_data.py     生成测试数据用
├── data/raw/
│   └── recruit_raw.csv     模拟的报名表（问卷导出格式）
└── output/                 跑出来的结果放这（已在 .gitignore 里）
```

## 数据说明

报名表一共 6 列：

| 字段 | 说明 |
| --- | --- |
| 姓名 | |
| 学号 | 10 位数字 |
| 邮箱 | 正常应该是 `学号@smbu.edu.cn` |
| 志愿1 | 必填 |
| 志愿2 | 可不填 |
| 推荐人 | 可不填 |

仓库里的 `data/raw/recruit_raw.csv` 是模拟数据。想重新生成跑一下：

```bash
python make_sample_data.py
```

随机种子是固定的，生成结果每次都一样。原始数据用 `utf-8-sig` 存，Excel 直接打开不会乱码。

## 用法

环境：Python 3.8 以上，无第三方依赖。

```bash
# 需求 1：读入并打印概览
# 需求 2：校验并导出问题清单
# 需求 3：统计并导出干净数据
```

## 边界假设

- **学号位数**：观察到的学号都是 10 位，格式为 `11202` + 入学年份末位 + 4 位序号
  （2026 级写作 `1120260001`）。本工具只强制「必须是纯数字」，**不校验位数和前缀**，
  避免把特殊情况的学号误判成脏数据。

# 招新报名数据清洗

社团每年招新会收到几百份报名表（问卷导出的 CSV），姓名、学号、邮箱都是手填的，
错漏不少：学号打成字母、邮箱留了自己的 QQ 邮箱、同一个人手抖报了两遍。这个小工具
就是把表读进来，先看一眼整体情况，再把有问题的行挑出来说明原因，最后按第一志愿
做个统计并导出干净数据。

只用了 Python 自带的标准库，不需要 pip 装任何东西。

## 目录

```
.
├── main.py                 主程序，三个子命令
├── make_sample_data.py     生成测试数据用
├── data/raw/
│   └── recruit_raw.csv     模拟的报名表（问卷导出格式）
└── output/                 跑出来的结果放这（已在 .gitignore 里）
```

## 数据说明

报名表一共 6 列：

| 字段 | 说明 |
| --- | --- |
| 姓名 | |
| 学号 | 10 位数字 |
| 邮箱 | 正常应该是 `学号@smbu.edu.cn` |
| 志愿1 | 必填 |
| 志愿2 | 可不填 |
| 推荐人 | 可不填 |

仓库里的 `data/raw/recruit_raw.csv` 是模拟数据。想重新生成跑一下：

```bash
python make_sample_data.py
```

随机种子是固定的，生成结果每次都一样。原始数据用 `utf-8-sig` 存，Excel 直接打开不会乱码。

## 用法

环境：Python 3.8 以上，无第三方依赖。

```bash
# 需求 1：读入并打印概览
python main.py overview
```

默认读 `data/raw/recruit_raw.csv`，可以 `-i` 换成别的文件：

```bash
python main.py overview -i 我的报名表.csv
```

输出长这样：

```
文件：data/raw/recruit_raw.csv
总行数：293（不含表头）

各列空值：
  姓名: 0
  学号: 0
  邮箱: 0
  志愿1: 0
  志愿2: 133
  推荐人: 165

完全重复的行：3 组
  第 54 行、第 270 行 一模一样（任雪）
  第 82 行、第 179 行 一模一样（方林佳）
  第 110 行、第 202 行 一模一样（林玉）
```

（注意：这里说的「行」是文件里从表头数起的行号，跟 Excel 里看到的行号一致。）

## 需求 2：校验并导出问题清单

```bash
python main.py clean
```

```

问题清单已导出 -> output/problem_list.csv

按类型统计：
  重复报名: 26 行
  邮箱不匹配: 13 行
  学号非纯数字: 7 行
```

导出的 `output/problem_list.csv` 在原始 6 列前面加了「行号」，后面加了「问题类型」和「问题说明」：

```
行号,姓名,学号,邮箱,志愿1,志愿2,推荐人,问题类型,问题说明
10,田丽丽,1120260257,112026025@smbu.edu.cn,视觉组,,,邮箱不匹配,邮箱应为 1120260257@smbu.edu.cn，实际填的是「112026025@smbu.edu.cn」
17,邱宁,112025 0062,112025 0062@smbu.edu.cn,算法组,宣传组,,学号非纯数字,学号「112025 0062」不是纯数字
51,方雨小,1120260051,1120260051@smbu.edu.cn,运营组,机械组,,重复报名,学号 1120260051 一共出现 2 次（第 174 行），本行保留
```

判定依据就三条：

| 问题类型 | 什么情况算 |
| --- | --- |
| 学号非纯数字 | 学号里有 0-9 以外的字符（空格、字母、横杠都算） |
| 邮箱不匹配 | 邮箱跟「学号@smbu.edu.cn」对不上 |
| 重复报名 | 同一个学号出现两次以上 |

**原始文件一个字节都没动**，所有结果都写到 `output/` 里。

## 边界假设

遇到拿不准的地方都记在这里，随时可以改。

- **学号位数**：观察到的学号都是 10 位，格式为 `11202` + 入学年份末位 + 4 位序号
  （2026 级写作 `1120260001`）。本工具只强制「必须是纯数字」，**不校验位数和前缀**，
  避免把特殊情况的同学误判成脏数据。
- **行号口径**：问题清单里的行号是文件里的实际行号（表头算第 1 行），不是数据序号，
  这样对着 Excel 直接就能找到人。
- **邮箱比较是区分大小写的**，`@SMbU.edu.cn` 会被判成填错。因为报名表里绝大多数
  邮箱都是复制出来的，严格比较反而更容易抓出问题。
- **重复报名怎么处理**：问题清单会把牵扯到的每一行都列出来（包括最早那条），
  但清洗时只保留最早的一行。如果最早那份本身填错了，会先被剔掉，再由后面
  正确的那份补上——不会因为填错一次就把人整个漏掉。
- **首尾空格**：判断「是不是空」和比较内容时会先把两端空格去掉（所以全角空格、
  半角空格都当空处理），但原始文件不动，只在导出的干净数据里统一去掉。
- **姓名和推荐人没做校验**，空着不算问题（推荐人本来就可以不填）。
